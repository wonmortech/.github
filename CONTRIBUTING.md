# Contributing

Thank you for helping. This guide applies to every repository in the `wonmortech` organization. If a repository has its own CONTRIBUTING file, that file wins.

## Where to go

| You want to | Go to |
|---|---|
| Report a bug or suggest a feature in a dtwin product, such as dtwin, bitg or TeleTwin | The product's repository in [github.com/dtwinuz](https://github.com/dtwinuz). The product code lives there. |
| Propose a change to the [charter](https://wonmor.io/charter/) | A public issue at [github.com/dtwinuz/.github](https://github.com/dtwinuz/.github), as the charter describes |
| Fix or improve the brand guidelines, this profile or other shared Wonmor material | An issue or pull request in the matching repository here |
| Report a security vulnerability | Not a public issue. See [SECURITY.md](SECURITY.md). |
| Ask anything else | Telegram: [t.me/xnosir](https://t.me/xnosir) |

## How a change gets in

1. **Issue.** For a larger change, open or pick an issue first, so we can agree on the direction before you spend time on it.
2. **Branch.** Branch from `main`, for example `feat/short-name` or `fix/short-name`.
3. **Commit.** Use the Conventional Commits style, such as `feat:`, `fix:` or `docs:`.
4. **Pull request.** Link the issue, fill in the template and keep it to one topic.
5. **Review.** At least one maintainer approval and green CI.
6. **Merge.** Squash merge; the branch is deleted afterwards.

## What we look for

- **Plain, accurate writing.** Wonmor material follows the charter: numbers must come from a measurement someone else can repeat, and plans are labelled "planned". A pull request that adds a claim should link to its source.
- **Small, focused changes.** One topic per pull request is easier to review and easier to revert.
- **The brand rules.** Changes to the brand files must follow the [brand guidelines](https://wonmor.io/brand/). Please do not redraw or recolour the mark.

## Sign-off and licences

No repository in this organization asks you to sign a contributor licence agreement (CLA), and sign-off is not currently required. What you contribute is released under the licence of the repository you contribute to. The brand files are not open-licensed; see the [brand repository](https://github.com/wonmortech/brand) for what that means.

## Code of conduct

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md), based on the Contributor Covenant 2.1.
